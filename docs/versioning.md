## Versioning & Tagging

- Use Semantic Versioning: `vMAJOR.MINOR.PATCH` (e.g., `v0.1.0`).
- Tag releases in Git and align package versions (PyPI/npm) with tags.
- Maintain concise CHANGELOGs per module (keep a `CHANGELOG.md`).
- For consulting: reference internal libraries by version to signal stability and test coverage.
